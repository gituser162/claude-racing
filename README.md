# Claude Racing

Аркадні 3D-перегони в стилі PS1 нічним кіберпанк-містом. Мемні гонщики (кур'єр «Швидка Пошта», офісний планктон, кіт-буханка, маршрутка, гусак, трактор, капібара у ванні) з двома скілами кожен: **Q** — з перезарядкою, **E** — ультімейт на останньому колі. 3 кола, гравець проти 6 ботів.

Рушій — **Godot 4.7** (GDScript, рендерер Compatibility, фізика Jolt).

## Як запустити
1. Встановити [Godot 4.7](https://godotengine.org/download).
2. Імпортувати проєкт (`project.godot`) і натиснути «Запустити» (F5).

## Керування
| Дія | Клавіатура | Геймпад |
|---|---|---|
| Газ / гальмо-назад | W / S | RT / LT |
| Поворот | A / D | Лівий стік |
| Скіл Q / ультімейт E | Q / E | X / Y |
| Повернутися на трасу | R | Back |
| Пауза | Esc | Start |

## Збірка
Пресети **Windows** і **Web** уже налаштовані: Проєкт → Експорт… (потрібні шаблони експорту 4.7). Деталі — у [DESIGN.md](DESIGN.md), розділ «Збірка».
