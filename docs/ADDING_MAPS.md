# Як додати нову мапу (трасу)

Документ має дві частини:
1. **Для тебе:** що написати Claude, щоб отримати нову мапу.
2. **Для Claude:** технічна інструкція. Claude читає її перед тим, як додавати мапу.

---

## Частина 1. Для тебе: шаблон запиту

```
Нова мапа
Назва: …
Сетинг / настрій: … (за замовчуванням — нічне кіберпанк-місто, див. DESIGN.md)
Характер траси: … (швидка з плавними поворотами / технічна зі шпильками / з трамплінами …)
Особливі місця: … (тунель, міст, розв'язка, зріз …)
Довжина кола: … (за замовчуванням ~45–60 с)
Короткий опис для меню (один рядок): …
```

**Правила:**
- **Стиль** — «сучасний PS1» (див. «Візуальні правила» в `DESIGN.md`). Нічне кіберпанк-місто — обов'язкова умова.
- **Бар'єри** ставляться автоматично із зовнішнього боку крутих поворотів; на пологих їх немає — звідти можна вилетіти.
- У меню мапа з'являється в рядку «ТРАСА» на екрані вибору гонщика.

**Як перевіряти:** Claude будує трасу, перевіряє, що боти проходять коло, і показує скріншоти. Ти запускаєш гру й кажеш, що не так.

---

## Частина 2. Для Claude: технічна інструкція

### Де що лежить (одна мапа = сцена траси + ресурс + 1 рядок)

| Що | Шлях | Примітка |
|---|---|---|
| Сцена траси | `scenes/track/<id>.tscn` | Корінь — `Node3D` зі скриптом `scripts/race/track.gd` (клас `Track`), дочірній `Path3D` з іменем `TrackPath` (крива по центру дороги) і дорога (`CSGPolygon3D` по цій кривій). Найпростіше — скопіювати `test_track.tscn` і змінити криву. |
| Дані мапи | `resources/maps/<NN>_<id>.tres` | Ресурс `MapData` (`scripts/data/map_data.gd`): `id`, `display_name`, `description` (один рядок), `scene_path`. |
| Реєстрація | `scripts/autoload/game.gd` → `MAP_PATHS` | Додати рядок зі шляхом до `.tres`. **Саме шлях, не `preload`** — інакше цикл залежностей і експортована гра не запускається (як і з гонщиками). |

### Як це працює
- `Game.MAPS` — завантажені `MapData`, `Game.selected_map` — обрана в меню.
- Сцена гонки (`scenes/main.tscn`) і фон меню містять вузол `TestTrack`. Одразу після створення сцени (`NOTIFICATION_SCENE_INSTANTIATED`) `Game.swap_in_selected_map($TestTrack)` ставить на його місце трасу обраної мапи з тим самим іменем, тож увесь код, що звертається до `$TestTrack`, працює без змін.
- Місто, ліхтарі, опори, арки, білборди й бар'єри будує `track.gd` вздовж кривої — нова траса отримує їх автоматично. Параметри (`road_width`, `checkpoint_count`, щільність міста, `barrier_max_radius` тощо) — експортовані змінні `Track`.

### Кроки перевірки
1. Імпорт без помилок (`--headless --editor --quit`).
2. Сцена гонки з цією мапою: машини стоять на старті, чекпоінти рахуються, коло зараховується.
3. Боти проходять коло без масових падінь (одне коло з усіма машинами).
4. Скріншоти: меню з новою мапою в рядку «ТРАСА», старт, кілька характерних місць траси.
5. Оновити `DESIGN.md` (розділ «Траса»).
